\# HireWise – Career Assistant Platform



HireWise is a web and mobile application designed to help users prepare for job opportunities, improve their resumes, and practice interview questions.



\## 🌐 Live Demo



\- \*\*Web Application:\*\* https://hire-wise-gamma.vercel.app

\- \*\*Backend API:\*\* https://hirewise-sju9.onrender.com

\- \*\*GitHub Repository:\*\* https://github.com/Ananya02Gupta/HireWise



\## ✨ Features



\- User Registration and Login

\- Forgot Password with Email OTP Verification

\- Resume Analyzer

\- Interview Preparation and Answer Feedback

\- Job Listings

\- Skill Insights

\- User Profile Management

\- Change Password

\- Web and Mobile Application Support



\## 🛠️ Tech Stack



\*\*Frontend:\*\* React.js, JavaScript, HTML, CSS



\*\*Mobile:\*\* React Native, Expo



\*\*Backend:\*\* Node.js, Express.js



\*\*Database:\*\* MongoDB



\*\*Tools:\*\* Git, GitHub, VS Code, Postman / Thunder Client



\*\*Deployment:\*\* Vercel, Render



\## 📱 Project Structure



\- `frontend/` – Web application

\- `backend/` – REST APIs and database integration

\- `mobile/` – React Native mobile application
